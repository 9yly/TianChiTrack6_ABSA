# 任务说明

# 电商评论观点挖掘任务详细说明

## 一、任务类型

本任务属于**细粒度情感分析（Aspect-Based Sentiment Analysis, ABSA）\**中的\**四元组抽取任务**，具体为从化妆品电商评论中抽取完整的观点四元组（Aspect-Category-Opinion-Sentiment Quadruple, ACOS）。

## 二、任务定义

### 核心目标

从用户评论文本中识别并抽取以下四个要素的组合：

- **AspectTerm（属性词）**：评论中提及的产品具体属性特征
- **OpinionTerm（观点词）**：对应属性的情感表达词汇
- **Category（属性类别）**：属性所属的预定义类别
- **Polarity（情感极性）**：观点的情感倾向

### 任务特点

1. **多元组抽取**：一条评论可能包含多个独立的四元组
2. **允许隐式表达**：AspectTerm或OpinionTerm可以为空（用"_"表示）
3. **严格匹配原文**：抽取的词汇必须与原文完全一致
4. **预定义类别**：Category和Polarity都是从固定集合中选择

## 三、输入输出规范

### 输入

- **格式**：CSV文件，包含id和Reviews两列

- **内容**：化妆品评论文本（已脱敏处理，品牌名用**代替）

- 示例

  ：

  ```
  id: 1Reviews: "很好，超值，很好用"
  ```

### 输出

- **格式**：CSV文件，每个四元组占一行

- **字段**：id, AspectTerm, OpinionTerm, Category, Polarity

- 要求

  ：

  - 空值用"_"表示
  - 必须包含所有测试集中的id（即使预测为空）
  - 无BOM的UTF-8编码
  - 不包含表头

### 预定义类别集合

**Category（13类）**：

```
{包装, 成分, 尺寸, 服务, 功效, 价格, 气味, 使用体验, 物流, 新鲜度, 真伪, 整体, 其他}
```

**Polarity（3类）**：

```
{正面, 中性, 负面}
```

## 四、训练数据说明

### 数据结构

训练集包含两个CSV文件：

1. **Train_reviews.csv**
   - 包含评论id和原文
   - 示例：`id=1, Reviews="很好，超值，很好用"`
2. **Train_labels.csv**
   - 包含标注的四元组及位置信息
   - 字段说明：
     - `id`：对应评论id
     - `AspectTerms`：属性词（可为"_"）
     - `A_start, A_end`：属性词在原文中的起止位置
     - `OpinionTerms`：观点词（可为"_"）
     - `O_start, O_end`：观点词在原文中的起止位置
     - `Categories`：属性类别
     - `Polarities`：情感极性

### 数据特征

- **一对多关系**：一条评论可对应多个四元组
- **隐式表达**：存在大量AspectTerm为空的情况（隐式属性）
- **噪声数据**：包含错别字、不规范符号等
- **品牌脱敏**：品牌名已用**替换

### 标注示例解析

以id=2的评论为例：

- 原文："很好，遮暇功能差一些，总体还不错"
- 抽取的四元组：
  1. `(_, 很好, 整体, 正面)` - 隐式属性的整体评价
  2. `(遮暇功能, 差一些, 功效, 负面)` - 明确的功效评价
  3. `(_, 还不错, 整体, 正面)` - 隐式属性的整体评价

## 五、测试数据说明

### 输入文件

- **Test_reviews.csv**：格式同训练集，包含id和Reviews

### 输出要求

- **文件名**：Result.csv

- 格式要求

  ：

  - 每行一个四元组：`id,AspectTerm,OpinionTerm,Category,Polarity`
  - 无表头
  - UTF-8无BOM编码
  - 必须包含所有测试id（空预测写作`id,_,_,_,_`）

### 提交示例

```csv
1,味道,香香的,气味,正面
1,物流,神速,物流,正面
2,_,好贵,价格,负面
3,_,_,_,_
```

## 六、评估指标

采用**四元组级别的F1-Score**作为评估标准：

- **精确匹配**：四个字段必须完全正确才算一个正确的四元组
- **Precision** = 正确预测的四元组数 / 预测的四元组总数
- **Recall** = 正确预测的四元组数 / 标注的四元组总数
- **F1-Score** = 2 × Precision × Recall / (Precision + Recall)

## 七、任务难点

1. **隐式属性处理**：大量评论的AspectTerm为空，需要推断属性类别
2. **多元组识别**：准确识别一条评论中的多个独立观点
3. **边界确定**：精确匹配原文中的AspectTerm和OpinionTerm
4. **类别映射**：将抽取的属性正确映射到13个预定义类别
5. **噪声处理**：处理错别字、不规范表达等问题
